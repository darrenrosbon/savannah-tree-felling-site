# Savannah Tree Felling

One page, mobile first website for Savannah Tree Felling, a tree felling business in Capital Park, Pretoria.
Static HTML, CSS and a little JavaScript. No build step. Open `index.html` in a browser, or serve the folder with any static server.

## Business details

- Phone and WhatsApp: +27 73 926 0524
- Address: 155 Flowers Street, Capital Park, Pretoria, 0084
- Hours: open 24 hours (per the Google listing)
- Services: risk tree felling, tree trimming, trunk and log cutting, palm trimming, green waste removal

## What is in the folder

- `index.html`: the whole site, with its styles and scripts inline
- `img/`: photos, logo cut-outs and the link preview image (`og-image.jpg`)
- `favicon.*`, `apple-touch-icon.png`, `icon-*.png`, `site.webmanifest`: icons and install settings
- `robots.txt`: search engine file
- `404.html`: page shown for unknown addresses

## How the quote form works

The form builds a friendly WhatsApp message from the visitor's name, suburb, chosen services and details, then opens WhatsApp to the business number. Nothing is stored or sent to a server.

Live site (GitHub Pages): https://darrenrosbon.github.io/savannah-tree-felling-site/

## When the web address changes

If the site moves to a custom domain, update the address in `index.html` (canonical link, `og:url`, `og:image`, `twitter:image`), `sitemap.xml` and `robots.txt`.
